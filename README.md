# FIFA World Cup 2026 Prediction & Simulation

## Project Overview

An ongoing Python and machine-learning portfolio project exploring international football results, predicting match outcomes and developing a simulation of the FIFA World Cup 2026.

The project is being developed incrementally, beginning with historical data analysis and a baseline classification model.

## Objectives

- Collect, clean and analyse historical international football results.
- Engineer pre-match team performance features.
- Develop a Random Forest classifier to estimate win, draw and loss probabilities.
- Evaluate predictions using chronological train/test splits.
- Build a tournament simulator incorporating the 2026 World Cup's 48-team format.
- Visualise predicted match outcomes and tournament progression.

## Technologies
